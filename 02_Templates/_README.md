# 02_Templates

- `Daily-Note.md` — English session log template (used by the daily-notes plugin)
- `Tagesnote.md` — German session log template

Both templates are wired into the daily-notes plugin (see `.obsidian/daily-notes.json`).
Switch the default template in Obsidian: Settings → Daily notes → Template file
location.
