# 01_Daily — Session Logs

**Rule:** one note per session/day, named `YYYY-MM-DD.md`. It records what
was worked on, decided, and blocked — so the next session (human or agent)
resumes without asking.

The daily-notes plugin creates the note automatically with the template from
`02_Templates/` (`Daily-Note.md` EN / `Tagesnote.md` DE).

**Rule:** Facts that will matter later get promoted from the daily note into
`MEMORY.md` (durable memory). The daily note is the log; `MEMORY.md` is the
memory.

# 01_Daily — Sitzungsprotokolle

**Regel:** Eine Notiz pro Sitzung/Tag, benannt `YYYY-MM-DD.md`. Sie hält fest,
was erledigt, entschieden und blockiert wurde — damit die nächste Sitzung
(Mensch oder Agent) ohne Rückfrage anknüpfen kann.

Das Daily-Notes-Plugin legt die Notiz automatisch mit der Vorlage aus
`02_Templates/` an (`Daily-Note.md` EN / `Tagesnote.md` DE).

**Regel:** Fakten, die später noch zählen, wandern aus der Tagesnotiz in
`MEMORY.md` (dauerhaftes Gedächtnis). Die Tagesnotiz ist das Protokoll;
`MEMORY.md` ist das Gedächtnis.
